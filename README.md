## 👨‍💻 About Me

I'm **Muhammad Shoaib Hashim**, a **Full-Stack Software Engineer, React Native Developer, and AI Engineer** building practical, scalable digital products across **iOS, Android, and the web**.

My work spans the full delivery lifecycle: **requirements analysis, UI/UX, mobile and web development, backend APIs, database-driven workflows, enterprise integrations, testing, and deployment**. I specialize in turning complex operational processes into intuitive applications for teams and customers.

- 📱 **Mobile:** React Native (CLI & Expo), cross-platform architecture, navigation, state management, native integrations, and app releases
- 🌐 **Full-stack:** Web applications, REST APIs, authentication, role-based access, and business workflows
- 🏢 **Enterprise:** Procurement, finance, employee self-service, inventory, governance, reporting, and approval systems
- 🔄 **SAP Business One:** ERP-connected workflows, document lifecycles, posting integrations, and operational data synchronization
- 🤖 **Applied AI:** OpenAI/GPT API integration, RAG, AI agents, workflow automation, and AI-enabled mobile features
- 🎨 **Product experience:** UI/UX design, design systems, responsive interfaces, and English/Arabic RTL support

> **What I build:** Software that makes complex business processes easier to operate, monitor, and scale.
